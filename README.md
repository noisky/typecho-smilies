# Typecho 评论表情插件 Smilies（百度贴吧表情版）

这是基于原版 Typecho Smilies 插件改造的版本，专门适配百度贴吧泡泡表情。插件不再提供 QQ、WordPress 或自定义表情集切换，仅使用仓库内置的 `paopao` 表情。

## 功能

- 评论框显示表情选择面板，点击表情即可插入对应代码。
- 自动将评论、文章和页面中的百度贴吧表情代码解析为图片。
- 文章和页面编辑器提供表情选择面板，方便插入表情代码。
- 内置普通尺寸和 `@2x` 高清图片：选择面板使用高清图，正文使用普通尺寸图片。
- 支持配置表情图片 CDN；不配置时使用插件本地图片。
- 表情面板固定展开，并使用原生 JavaScript，不依赖 jQuery。

## 环境要求

- Typecho `14.10.10` 或更高版本（插件声明的依赖范围为 `14.10.10-*`）。
- 主题需要提供可识别的评论文本框，并调用 Typecho 的页脚钩子。

## 安装

1. 将仓库目录复制到 Typecho 的 `usr/plugins/Smilies/`，目录名必须保持为 `Smilies`。
2. 确认 `Plugin.php`、`smilies.css` 和 `paopao/` 目录位于该插件目录下。
3. 在 Typecho 后台的“控制台 → 插件”中启用 **Smilies**。
4. 在插件配置页按需设置 CDN、评论框 ID 和“正文使用表情”。

## 在主题中显示评论表情面板

在主题 `comments.php` 中评论文本框附近加入：

```php
<?php if (\Typecho\Plugin::exists('Smilies') && class_exists('Smilies_Plugin')): ?>
    <?php Smilies_Plugin::output(); ?>
<?php endif; ?>
```

前台主题还需要加载插件样式。可在主题 `<head>` 中加入：

```php
<link rel="stylesheet" href="<?php $this->options->pluginUrl('Smilies/smilies.css'); ?>">
```

后台文章/页面编辑器会在“正文使用表情”开启时自动加载该样式。前台 `output()` 只输出面板 HTML，不会自动插入 CSS。

如果点击表情后没有插入内容，请在插件配置中填写“指定评论框 ID”。留空时，单页评论默认查找第一个 `textarea`；列表场景使用 `text` 作为目标 ID。

## 配置说明

### 表情图片 CDN 地址

留空时从当前 Typecho 站点加载 `Smilies/paopao/` 下的图片。填写 CDN 根地址后，插件会从该地址的 `paopao/` 子目录加载图片，例如：

```text
https://cdn.example.com/usr/plugins/
```

CDN 上应保持原有文件名和目录结构，并支持 UTF-8 中文文件名；`smilies.css` 始终从插件本地地址加载。生产环境建议使用 HTTPS。

### 正文使用表情

开启后（默认开启）：

- 文章和页面编辑器显示表情选择面板；
- 文章、页面正文及摘要中的表情代码会转换为图片。

关闭后，插件仍可用于评论表情，但不处理正文，也不显示编辑器表情面板。

## 从原版升级

本版本的配置和资源结构已经改变：

- 删除了 `qq/` 和 `wordpress/` 两套旧表情资源；
- 移除了表情风格选择、拖动排序、字符表情替换、最大宽度、弹窗和 jQuery 模式等旧选项；
- 表情集固定为百度贴吧泡泡表情，配置项只保留 CDN、评论框 ID 和正文开关。

升级后请重新检查插件配置，并确认主题已加载 `smilies.css`。

## 文件说明

- `Plugin.php`：插件逻辑、代码映射、Typecho 钩子和前台/后台输出。
- `paopao/`：百度贴吧泡泡表情图片，包含普通尺寸和 `@2x` 高清版本。
- `smilies.css`：表情面板布局及交互样式。
- `custom.css`、`custom.js`：原版后台预览/拖动排序资源，当前版本不再由 `Plugin.php` 加载，不是运行所必需的文件。
